## ⚠️ 데이터 활용 시 유의사항

`03`, `04`, `11` 등 대학별 입시결과·권장과목 수치는 **2025학년도 수시(2024년 실시) 기준 참고자료**입니다. 대학의 모집인원·전형방법·컷트라인·권장과목은 **매년 변경**되므로, 실제 학생 상담과 지원 전략 수립 시에는 반드시 해당 대학 입학처의 최신 공식 모집요강과 입시결과 발표 자료로 재확인하시기 바랍니다. 웹북 내 관련 섹션에도 동일한 안내 문구를 표기해 두었습니다.
